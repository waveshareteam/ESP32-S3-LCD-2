# LVGL 音乐播放器界面

[English](README.md) | [简体中文](README_ZH.md)

## 功能

在板载 LCD 上显示 LVGL 音乐播放器演示界面。

## 硬件需求

- ESP32-S3-LCD-2 开发板和 USB 数据线

## 怎么运行

使用 [仓库首页](../../../README_ZH.md) 所列版本的 ESP-IDF，在本目录中打开 ESP-IDF 终端。

```bash
idf.py set-target esp32s3
idf.py build flash monitor
```

## 预期现象

LCD 显示专辑封面和播放器控件。
