# LVGL music player interface

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Displays the LVGL music player demo interface on the onboard LCD.

## Hardware Required

- ESP32-S3-LCD-2 development board and USB data cable

## How to Run

Open an ESP-IDF terminal in this directory using a version listed in the [repository README](../../../README.md).

```bash
idf.py set-target esp32s3
idf.py build flash monitor
```

## Expected Result

The LCD shows album art and the music player controls.
